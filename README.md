# UX Projects | KeelWorks

A centralized repository for UX design projects, interactive HTML prototypes, design system resources, and UX-to-development handoff materials developed for **KeelWorks Foundation**.

## Overview

This repository provides a shared space to organize, demonstrate, and maintain UX design work across KeelWorks initiatives.

It supports collaboration between UX designers, product managers, developers, and other stakeholders by providing accessible references for design reviews, functional requirements, and implementation.

## Projects

| Project | Description |
|---|---|
| **KeelLearn** | UX designs and interactive prototypes for the KeelLearn learning management platform, including instructor dashboards and student progress tracking. |
| **KeelWorks Website** | Website redesign concepts, navigation improvements, fundraising experiences, and responsive page prototypes. |
| **Portfolio Generator** | UX prototypes and design assets supporting the portfolio creation experience. |
| **Design System** | Reusable UI components, design foundations, interaction patterns, and accessibility guidelines. |

*Additional projects and resources will be added as development continues.*

## Purpose

- **Design Exploration:** Demonstrate UX concepts and alternative design approaches.
- **Interactive Prototyping:** Validate page layouts, user interactions, and responsive behavior.
- **Design Reviews:** Share prototypes with team members and stakeholders for feedback.
- **Development Handoff:** Provide visual and functional references to support implementation.
- **Knowledge Sharing:** Preserve UX project resources and design decisions for future team members.
